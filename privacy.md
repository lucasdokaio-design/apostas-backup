# Política de Privacidade

O Apostas Backup é uma ferramenta de uso pessoal que usa o Google Drive para armazenar cópias dos registros do projeto Apostas.

O acesso ao Drive usa a permissão drive.file para criar, consultar e gerenciar os arquivos de backup autorizados para o aplicativo. O servidor guarda a autorização do Google para executar os backups agendados.

Os dados do Drive são usados para guardar, conferir e restaurar os backups do projeto. O aplicativo não vende esses dados nem os usa para publicidade.

O titular da conta pode remover o acesso do aplicativo nas configurações da Conta Google e excluir os backups pelo próprio Google Drive.
